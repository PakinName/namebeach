# NovaX: ระบบบัญชีและการเรียน — 18 ตุลาคม 2569

## วิธีใช้งาน
1. สมัครสมาชิก: แยกชื่อจริง–นามสกุล ชื่อแสดงในระบบ และชื่อเล่น มีปุ่มแสดง/ซ่อนรหัสผ่านทั้งสองช่อง
2. ครูสมัครใหม่: รอแอดมินอนุมัติที่ ศูนย์จัดการระบบ → บัญชีผู้ใช้ → อนุมัติครู ครูเดิมยังใช้ได้
3. แอดมิน: แก้ชื่อ อีเมล บทบาท ชื่อจริง ชื่อเล่น เปิด/ปิดบัญชี รีเซ็ตรหัสผ่าน และลบบัญชีออกจากการใช้งาน การลบเก็บประวัติ คอร์ส และเกียรติบัตรไว้ ไม่ล้างฐานข้อมูล ไม่อนุญาตลบตนเองหรือปิดแอดมินคนสุดท้าย มีตัวกรองครูรออนุมัติและบัญชีที่ลบออก กู้คืนบัญชีได้โดยยังปิดการใช้งานไว้จนแอดมินเปิดอีกครั้ง
4. นักเรียน: เข้าร่วมคอร์สก่อน เรียนและกดจบเรื่องตามลำดับ เรียนทุกเรื่องในบทก่อนสอบ ผ่านแบบทดสอบท้ายบทก่อนเข้าบทถัดไป ไม่สามารถข้ามด้วย URL หรือ API ได้
5. ครู: จัดการแบบทดสอบ → เลือกบท → แก้คำถามหรือเพิ่มข้อ เลือกข้อกา จริง/เท็จ หรือข้อเขียน กำหนดคะแนนและเกณฑ์ผ่าน แล้วบันทึก
6. ข้อเขียน: ในหน้าเดียวกัน ใต้ผลสอบจะมีคำตอบรอตรวจ ใส่คะแนนและคำแนะนำทุกข้อ แล้วกดยืนยันคะแนน นักเรียนจะเห็นผลเมื่อเปิดแบบทดสอบใหม่ ผลผ่านจึงปลดล็อกบทถัดไป
7. เปลี่ยนข้อสอบได้แม้มีประวัติแล้ว คำถามเก่าและเกณฑ์ผ่าน ณ เวลาส่งถูกเก็บไว้กับผลสอบ แก้ฉบับใหม่ไม่เปลี่ยนผลเดิม หากครูแก้ระหว่างนักเรียนทำ นักเรียนต้องโหลดข้อสอบใหม่ก่อนส่ง
8. บทที่ไม่มีข้อสอบได้รับแบบทบทวนข้อเขียน 1 ข้อ (สองแนวคิดสำคัญและตัวอย่างการใช้) มีเกณฑ์ให้ครูตรวจ ครูปรับเป็นข้อกาได้ คอร์สใหม่สร้างแบบทบทวนท้ายบทให้ด้วย
9. โปรไฟล์: แก้ชื่อจริง ชื่อเล่น ชื่อแสดง เบอร์โทร ประวัติย่อ และเปลี่ยนรหัสผ่านโดยยืนยันรหัสเดิม เกียรติบัตรแสดงชื่อจริงเท่านั้น บัญชีเดิมต้องกรอกชื่อจริง ไม่เดาจาก username
10. ผู้ช่วย AI: เปิดจากหน้าบทเรียน จะเตรียมคำถามสรุปและแนบบทเรียนนั้นโดยอัตโนมัติ กดส่งเพื่อรับคำตอบ ผู้ช่วยไม่มีสิทธิ์อ่านบทเรียนที่ยังล็อก
