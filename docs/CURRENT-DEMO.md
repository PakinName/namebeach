# NovaX — ลิงก์สาธิตชั่วคราว

https://promises-ebony-boat-olympus.trycloudflare.com

รหัสเข้าชมอยู่ใน .data/share/access.json ให้ส่งเฉพาะอาจารย์ที่ต้องการสาธิต
Cloudflare → gateway 127.0.0.1:3001 → Next.js 127.0.0.1:3000
เครื่อง อินเทอร์เน็ต PostgreSQL Ollama และโปรเซส tunnel ต้องเปิดอยู่
NEXTAUTH_URL ใช้ลิงก์ด้านบนสำหรับโปรเซสเว็บเดโมนี้ รีสตาร์ต tunnel อาจได้ลิงก์ใหม่
