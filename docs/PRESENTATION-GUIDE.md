# AI LMS — คู่มือพรีและส่งงาน
วันที่ตรวจ: 14 ตุลาคม 2026

## เปิดระบบก่อนพรี
1. เปิด PostgreSQL ที่โปรเจกต์ตั้งไว้ (localhost:5433)
2. เปิด Ollama หรือใช้ `ollama serve` หากยังไม่ได้เปิด
3. ในโฟลเดอร์โปรเจกต์ รัน `npm run start` หลัง build แล้ว
4. เปิด http://127.0.0.1:3000 และทดสอบเข้าสู่ระบบก่อนเริ่มพรี
5. หากเพิ่งติดตั้งใหม่: `npm ci`, ตั้ง `.env.local`, `node scripts/prisma-local.cjs migrate deploy`, `npm run build`
6. ระบบต้องมีข้อมูลบัญชี/รายวิชาในฐานข้อมูล ห้ามรัน reset หรือ seed ทับฐานข้อมูลใช้งานโดยไม่ตรวจสอบ

## หน้าที่ควรเปิดเตรียม
- /admin — จัดการบัญชีและคอร์ส
- /admin/activity — ประวัติล็อกอิน สำเร็จ/ล้มเหลว ออกจากระบบ และกิจกรรมที่มี Audit Log
- /courses/new — สร้างคอร์สด้วยตนเอง
- /quiz-builder — จัดการข้อสอบ
- /dashboard — ภาพรวมการเรียน
- /certificates — เกียรติบัตร
- /assistant — ผู้ช่วย AI
- /support — รับเรื่องและตอบกลับ

## อธิบายสถาปัตยกรรม
Next.js + React เป็นเว็บและ API, NextAuth จัดการเข้าสู่ระบบ, Prisma เชื่อม PostgreSQL
Ollama รันโมเดลบนเครื่อง; Gemini เรียกผ่านเซิร์ฟเวอร์ คีย์ไม่ส่งเข้า browser
API ตรวจบทบาทและสถานะบัญชีจากฐานข้อมูล ข้อมูลประวัติ AI แยกเจ้าของ
ตารางสำคัญ: User, Course, Chapter, Lesson, QuizAttempt, Certificate, LoginEvent, AuditEvent

## ผลตรวจรอบนี้
- Production build และ TypeScript ผ่าน
- Integration: login success/failure/logout และผู้ที่ไม่ใช่แอดมินอ่านประวัติไม่ได้
- Integration: สิทธิ์บัญชี ระงับบัญชี แอดมินคนสุดท้าย กล่องร้องเรียน และการแยกข้อมูล
- Integration: ครูสร้าง/แก้คอร์ส ไฟล์และรูป ลำดับบท และการล็อกบท
- Integration: ข้อสอบ คะแนน ความคืบหน้า และเกียรติบัตรรายวิชา ไม่ออกก่อนครบ/ไม่ออกซ้ำ
- Lint ไม่มี error; มี warning เดิมเรื่องตัวแปร admin ใน prisma/seed.ts

- ทดสอบสด 14 ตุลาคม: Llama 3.2, Qwen3 และ Gemini 3.1 Flash Lite ตอบภาษาไทยและบันทึกประวัติผ่าน

## ขอบเขตที่ควรบอกตามจริง
- ประวัติล็อกอินเริ่มเก็บหลังติดตั้งฟีเจอร์นี้ ไม่ใช่รายการผู้ที่ออนไลน์อยู่ และไม่มีข้อมูลย้อนหลังที่ไม่เคยบันทึก
- Audit Log แสดงเฉพาะกิจกรรมที่มีการเพิ่มจุดบันทึกไว้ ไม่ครอบคลุมทุกการคลิก
- ข้อสอบรองรับปรนัยและถูก/ผิด ยังไม่เทียบเท่าระบบแบบฟอร์มทุกชนิด
- ยังไม่มีลืมรหัสผ่านผ่านอีเมล/ระบบแจ้งเตือนอีเมล
- PDF ใช้ Print/Save as PDF ในเบราว์เซอร์
- AI ภายนอกขึ้นกับเครือข่ายและโควตา; หากช้าสลับ Llama บนเครื่อง
- localhost ใช้บนเครื่องนี้ ลิงก์เผยแพร่ต้องตั้ง hosting หรือ tunnel แยก
- ยังไม่ได้ตรวจ responsive ทุกหน้าหรือทำ full database restore rehearsal

## ก่อนส่งไฟล์
- ส่ง source, prisma/migrations, package.json, package-lock.json และคู่มือนี้
- ไม่ส่ง .env/.env.local, .data, node_modules, .next หรือ backup ที่มีข้อมูลผู้ใช้โดยไม่ได้คัดกรอง
- ไม่แนบรหัสผ่านหรือคีย์ลงรายงาน/ภาพหน้าจอ
- ค่าลับและรหัสที่เคยเผยในแชต/ภาพควรเปลี่ยนก่อนเผยแพร่จริง รอบนี้ไม่ได้หมุนคีย์แทนเจ้าของบัญชี
- สั่ง `node scripts/backup-database.cjs` ก่อนแก้ฐานข้อมูล สำเนาอยู่ .data/backups; จัดเก็บแยกจากชุด source
- การกู้คืนให้ใช้ฐานข้อมูลใหม่เพื่อซ้อมก่อน ห้าม restore ทับฐานข้อมูลใช้งานทันที
