# คู่มือ UI สองภาษาและผู้ช่วยการเรียนรู้

## เปิดโปรเจค
ใช้โฟลเดอร์ราก `ai-lms-project (1)` (ไม่ใช่โฟลเดอร์สำเนา `ai-lms-project` ข้างใน)

```powershell
npm run dev
```
สำหรับ production preview: `npm run build` แล้ว `npm run start`

## โครงสร้าง
- `src/app/globals.css`: สี ระยะห่าง ฟอร์ม การ์ด responsive และธีมมืดร่วมกัน
- `src/components/ui`: ส่วนประกอบร่วม เช่น Icon, PageHeader, Dialog, CourseCard
- `src/components/layout`: Header, Sidebar และปุ่มเปลี่ยนภาษาด้านบน
- `src/components/providers/LanguageProvider.tsx`: ภาษาเริ่มต้นไทย จดจำการเลือกด้วย localStorage และอัปเดต `html.lang`
- `src/lib/i18n/th.ts`: พจนานุกรม UI ใช้ข้อความอังกฤษเป็น key เรียกผ่าน `t()`
- `src/app/(dashboard)/assistant/page.tsx`: แชตหลายรอบ ตัวเลือกแหล่งคำตอบ หยุดคำตอบ และลิงก์บทเรียนอ้างอิง
- `src/lib/ai.ts`: เชื่อม OpenAI Responses และ Gemini generateContent จากเซิร์ฟเวอร์
- `src/lib/learning-context.ts`: ค้นและตรวจสิทธิ์บทเรียนก่อนส่งบริบท

ข้อความ UI รองรับไทย/อังกฤษ เนื้อหาคอร์ส ชื่อบทเรียน ข้อสอบ และประกาศที่ผู้สอนบันทึกยังคงต้นฉบับ ไม่แปลข้อมูลในฐานข้อมูลโดยอัตโนมัติ

## เปิดใช้งานโมเดล AI
เพิ่มอย่างน้อยหนึ่ง provider ใน `.env.local` ด้วย key จริงของคุณ แล้วเริ่มเซิร์ฟเวอร์ใหม่:

```dotenv
OPENAI_API_KEY=your-real-key
OPENAI_MODEL=gpt-4.1-mini
GEMINI_API_KEY=your-real-key
GEMINI_MODEL=gemini-3.8-flash
```

ไม่ต้องใส่ทั้งสองบริการ หากมีทั้งสอง Auto เลือก Gemini ก่อน OpenAI; ผู้ใช้เลือกเองได้ในหน้าแชต ห้ามใช้ prefix `NEXT_PUBLIC_` กับ key

เมื่อไม่มี key ระบบใช้ **ค้นข้อความจากบทเรียน** พร้อมระบุว่าไม่ใช่คำตอบที่โมเดล AI สร้าง ไม่ส่งคำถามออกไปยังบริการภายนอก โหมด AI ส่งคำถาม ประวัติสนทนาช่วงล่าสุด และข้อความบทเรียนที่เข้าถึงได้ไปยังผู้ให้บริการที่เลือก

เปิดผู้ช่วยจากหน้าบทเรียนเพื่อถามในบริบทนั้น หรือใช้เมนูผู้ช่วยเพื่อถามทั่วไป ประวัติอยู่ในหน้านี้เท่านั้น ไม่บันทึกในฐานข้อมูล

API สร้างข้อสอบ `/api/ai/generate-quiz` อนุญาตครู/แอดมิน ส่ง `topic`, `numQuestions`, `difficulty`, `language`, `provider` ได้ ผลลัพธ์เป็นร่างที่ผ่านการตรวจรูปแบบ ไม่มีการบันทึกหรือตีพิมพ์อัตโนมัติ

มี timeout 30 วินาที และจำกัด 30 คำขอต่อผู้ใช้ต่อ 10 นาทีใน process เดียว หาก deploy หลาย instance ให้ย้าย limiter ไป shared storage

อ้างอิง: [OpenAI text generation](https://developers.openai.com/api/docs/guides/text), [Gemini generateContent](https://ai.google.dev/api/generate-content)

## ตรวจสอบ
```powershell
npx tsc --noEmit --incremental false
npm run lint
npm run build
node scripts/test-ai.cjs
```
`test-ai.cjs` ทดสอบ provider และ error handling โดย mock network ไม่ใช้ key จริง

ขณะเซิร์ฟเวอร์ localhost:3000 ทำงานและฐานข้อมูลมีบัญชีตัวอย่างจาก seed:
```powershell
node scripts/test-ai-integration.cjs
```
ทดสอบ login การค้นบทเรียน การปฏิเสธบทเรียนล็อก input ผิด และสิทธิ์สร้างข้อสอบ โดยไม่แก้ไข records

ทดสอบ UI แล้ว: สลับไทย/อังกฤษ จดจำหลังรีโหลด ค้นบทเรียนจากแชต และหน้าจอมือถือ 390px
ก่อนเปลี่ยนผู้ช่วยเป็น Ollama เคยทดสอบ Gemini ผ่าน `/api/ai/chat` ได้ HTTP 200; ปัจจุบันผู้ช่วยใช้ Llama ตามหัวข้อด้านล่าง

## สร้างคอร์สด้วย AI (อาจารย์)
- นำเมนูห้องเรียนออกทุกบทบาท; URL เดิมส่งครู/ผู้ดูแลไป `/course-builder` และนักเรียนไป `/courses`
- ครู/ผู้ดูแลสร้างร่างจากหัวข้อ คำอธิบาย syllabus และ PDF/TXT/MD ไม่เกิน 5 MB (ข้อความไม่เกิน 30,000 ตัวอักษร)
- เอกสารส่งให้ Gemini เฉพาะคำขอสร้างร่าง ไม่บันทึกไฟล์ลงเซิร์ฟเวอร์
- ตรวจร่างก่อนบันทึก คอร์สที่บันทึกมี `published: false`; นักเรียนและครูคนอื่นไม่สามารถเปิดเนื้อหาฉบับร่างได้
- `node scripts/check-course-builder.cjs` ตรวจการบันทึกและสิทธิ์ด้วยข้อมูลจำลอง แล้วลบเฉพาะร่างทดสอบที่สร้างเอง
- ตั้ง `RUN_LIVE_AI=1` เพื่อทดสอบ Gemini จริงด้วย (อาจใช้โควตา)
- การทดสอบล่าสุด: build/TypeScript ผ่าน, การบันทึกและสิทธิ์ผ่าน; Gemini จริงตอบ 503 และ 429 จึงยังไม่ยืนยัน generation ของคอร์สรอบนี้

## ผู้ช่วยแชต Llama บนเครื่อง
หน้า `/assistant` ใช้ `llama3.2:3b` ผ่าน Ollama แทน Gemini ค่า `auto` ใน Chat API เลือก Ollama โดยตรง ไม่มีการเปลี่ยนไป cloud อัตโนมัติเมื่อ Ollama ปิดอยู่ เมนูค้นจากบทเรียนยังแยกจากโมเดล AI

```dotenv
OLLAMA_BASE_URL=http://127.0.0.1:11434
OLLAMA_MODEL=llama3.2:3b
```

เปิดแอป Ollama ก่อนใช้งานเว็บ หากไม่มีโมเดลให้ใช้ `ollama pull llama3.2:3b` หน้าผู้ช่วยตรวจโมเดลจริงผ่าน `/api/tags` และแสดงสถานะพร้อมใช้งาน API เรียกจากเซิร์ฟเวอร์เท่านั้น ไม่จำเป็นต้องเปิดพอร์ต Ollama สู่อินเทอร์เน็ต

คำถาม ประวัติช่วงล่าสุด และเนื้อหาบทเรียนจะประมวลผลที่ Ollama ตาม URL ที่ตั้งไว้ การรันโมเดล local ไม่ใช้โควตา Gemini ความเร็วขึ้นกับเครื่อง ตั้ง context 8192 และเวลารอสูงสุด 180 วินาทีเพื่อรองรับการโหลดครั้งแรก ยังคงตรวจสิทธิ์บทเรียนก่อนส่งบริบท

หน้าสร้างคอร์สและแนบ PDF ยังใช้ Gemini; การเปลี่ยนนี้จำกัดเฉพาะผู้ช่วยแชต

ตรวจการถามตอบจริงผ่านเว็บ: `node scripts/test-ollama-live.cjs` (ต้องมีบัญชี seed และเว็บรันที่พอร์ต 3000)
ทดสอบจริงวันที่ 6 ตุลาคม 2026: พร้อมใช้งานโมเดล `llama3.2:3b`, ถามภาษาไทยและถามต่อสำเร็จผ่าน Chat API โดยคืน provider `ollama`; คำขอแรกใช้ประมาณ 40 วินาทีรวมโหลดโมเดล
เอกสาร: https://docs.ollama.com/api/chat

## สร้างคอร์สด้วยตัวเอง
ครูและผู้ดูแลเข้า `/courses/new` จากเมนูหรือปุ่มในคลังคอร์ส กรอกข้อมูลคอร์ส บท และบทเรียนได้โดยไม่เรียก AI รองรับ 8 บท บทละ 5 บทเรียน พร้อมวัตถุประสงค์และเวลาเรียน ปุ่มบันทึกและเผยแพร่ทำให้คอร์สปรากฏในคลังของนักเรียนทันที

POST `/api/courses` ตรวจโครงสร้างข้อมูลและสิทธิ์ กำหนดเจ้าของจาก session และสร้างคอร์ส/บท/บทเรียนใน nested write เดียว บทที่ไม่มี quiz จะเสร็จสมบูรณ์และปลดล็อกบทถัดไปเมื่อเรียนครบทุกบทเรียน; บทที่มี quiz คงใช้เกณฑ์สอบเดิม การบันทึกเรียนจบตรวจคอร์สเผยแพร่และสิทธิ์เข้าถึงบทก่อนเสมอ

ตรวจสอบด้วย `node scripts/test-manual-course.cjs` (สร้างและลบ fixture ของตัวเอง): สิทธิ์ครู/นักเรียน, validation, เจ้าของคอร์ส, การเผยแพร่, ลำดับบทเรียน และการปลดล็อกบทเมื่อเรียนครบ ผ่านแล้ว รวมถึง UI สร้างคอร์สและเปิดรายละเอียดจริง, TypeScript และ production build ผ่าน

## Course editor (8 October 2026)
- เจ้าของคอร์สและแอดมินเข้า `/courses/[id]/edit` ผ่านปุ่มจัดการคอร์สในหน้ารายละเอียด หรือหลังสร้างคอร์สด้วยตัวเอง/AI
- แก้ข้อมูลคอร์ส สถานะร่าง/เผยแพร่ รูปปก ชื่อ/คำอธิบายบท เพิ่ม/ลบ/จัดลำดับบทและบทเรียนได้ ภายในขอบเขต 40 บท / 50 บทเรียนต่อบท / 200 บทเรียนรวม
- บทความรองรับ 100,000 ตัวอักษร และ Markdown แบบหัวข้อ ตัวหนา รายการและโค้ด พร้อมตัวอย่างและตัวแก้ไขแบบขยาย; ไม่รัน HTML
- เพิ่มวัตถุประสงค์ เวลาเรียน ตัวอย่างโค้ด วิดีโอ YouTube/MP4 รูปภาพ PDF preview สไลด์ และเอกสารประกอบได้
- รองรับไฟล์ PNG/JPEG/WebP, PDF, TXT/MD/CSV, DOCX/PPTX/XLSX ขนาดสูงสุด 15 MB ตรวจส่วนหัวไฟล์ก่อนรับ และไม่รับ HTML/SVG/executable
- ไฟล์เก็บใน `.data/course-assets` บนเครื่องเซิร์ฟเวอร์ (ถูก gitignore) และ metadata ใน FileUpload; เมื่อย้าย/สำรองระบบต้องเก็บทั้งโฟลเดอร์นี้และฐานข้อมูล ต้องใช้ persistent storage ใน production
- ไฟล์เปิดผ่าน authenticated API เท่านั้น; นักเรียนต้องเห็นคอร์สและมีสิทธิ์บทเรียนก่อนเปิดเอกสารในบท ไฟล์ที่ยังไม่แนบเปิดได้เฉพาะเจ้าของ/แอดมิน รูปปกของคอร์สเผยแพร่เปิดได้กับผู้เข้าสู่ระบบ
- นำไฟล์ออกจากบทเรียนไม่ลบต้นฉบับในคลัง เพื่อใช้ซ้ำได้
- PUT `/api/courses/[id]/manage` ใช้ transaction และ updatedAt ตรวจการบันทึกชนกัน คง IDs ของเนื้อหาเดิมและประวัติการเรียน ไม่ยอมลบเนื้อหาที่มี progress, quiz, completion หรือ scheduled lesson
- บทใหม่หลังบทที่นักเรียนเรียนจบแล้วเข้าได้ โดยยังเคารพบทที่ล็อกอื่นตามลำดับเดิม
- UI แจ้งเตือนเมื่อออกโดยไม่บันทึก; ไม่มี autosave ขึ้นเซิร์ฟเวอร์ ผู้ใช้ต้องกดบันทึกการแก้ไข
- ตรวจผ่าน: `scripts/test-course-editor.cjs`, `scripts/test-manual-course.cjs`, TypeScript, lint (มี warning เดิมใน seed.ts) และ production build รวมถึงทดสอบบันทึก/แนบไฟล์/ดูบทเรียนผ่านหน้าเว็บจริงและจอมือถือ 390px ข้อมูลทดสอบถูกลบแล้ว
