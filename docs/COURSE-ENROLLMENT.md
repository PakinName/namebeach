# ฉบับร่าง การเผยแพร่ และการเข้าร่วมคอร์ส

ครูเปิด /courses จะเห็นเฉพาะคอร์สของตนเอง แยกแท็บทั้งหมด / ฉบับร่าง / เผยแพร่แล้ว (แอดมินเห็นทุกคอร์ส)
- สร้างคอร์สใหม่: เลือกบันทึกฉบับร่าง (ค่าเริ่มต้นในฟอร์ม) หรือเผยแพร่ทันที
- การ์ดคอร์ส: แก้ไขเนื้อหา เผยแพร่ให้นักเรียน หรือเก็บเป็นฉบับร่าง
- ตั้งรหัสเข้าคอร์สอย่างน้อย 6 ตัว แล้วส่งรหัสให้นักเรียนด้วยตนเอง ระบบเก็บเฉพาะ bcrypt hash
- คอร์สที่ยังไม่ตั้งรหัสยังเปิดเรียนได้เหมือนเดิม ตั้งรหัสก่อนเผยแพร่ถ้าต้องการจำกัดสมาชิก
- นักเรียนเปิดคลังคอร์ส เลือกวิชา กรอกรหัสจากครู และกดเข้าร่วมคอร์ส
- นักเรียนที่เข้าร่วมแล้วเปิดเรียนได้โดยไม่กรอกรหัสซ้ำ การเปลี่ยนรหัสไม่ยกเลิกสมาชิกเดิม
- เมื่อเก็บเป็นฉบับร่าง เนื้อหาจะไม่เปิดให้นักเรียนอ่าน แม้เคยเข้าร่วมแล้ว ประวัติเรียนยังอยู่
- สถานะฉบับร่างเป็นสถานะของคอร์สเดียว ยังไม่ใช่ระบบเก็บ revision ฉบับร่างแยกคู่กับฉบับเผยแพร่
- จำกัดรหัสผิด 10 ครั้งต่อบัญชี/คอร์ส ใน 10 นาที เป็นตัวจำกัดในโปรเซสสำหรับเซิร์ฟเวอร์เดโมเครื่องเดียว

ทดสอบผ่าน: teacher ownership, draft invisibility, unpublished join denied, wrong code denied, lesson access denied before joining, unique enrollment, existing member access after code rotation, course/editor/platform regression

นักเรียนเข้าเมนู เข้าร่วมคอร์สเรียน (/join) เพื่อค้นหาตามวิชาหรือชื่อครู เลือกคอร์ส กรอกรหัส และเปิดแท็บคอร์สที่เข้าร่วมแล้วได้โดยตรง
