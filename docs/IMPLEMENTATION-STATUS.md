# สถานะระบบ — 13 ตุลาคม 2026

## ทำแล้ว
- แอดมิน: จัดการบัญชี บทบาท เปิด/ปิดบัญชี ป้องกันการปิดแอดมินคนสุดท้าย สถิติจริง ลิงก์แก้คอร์ส และประกาศส่วนกลาง พร้อมบันทึกการเปลี่ยนแปลง
- ตรวจบทบาทและสถานะบัญชีจากฐานข้อมูลใน API ที่ต้องเข้าสู่ระบบ
- รับเรื่องร้องเรียน: รายการของตนเอง/กล่องรวมแอดมิน ตอบกลับ เปลี่ยนสถานะ และแจ้งเตือนภายในเว็บ
- นักเรียน: แยกคอร์สยังไม่เริ่ม/กำลังเรียน/สำเร็จจากบทเรียนและผลสอบจริง พร้อมเรียนต่อ
- เกียรติบัตร: ออกแยกรายวิชาเมื่อผ่านแบบทดสอบทุกบท (บทที่ไม่มีแบบทดสอบต้องเรียนครบทุกบทเรียน) ตรวจสอบด้วยรหัสสาธารณะ แอดมินเพิกถอนได้ พิมพ์หรือ Save as PDF ผ่านเบราว์เซอร์
- ครู: สร้างและแก้แบบทดสอบปรนัย/ถูกผิด ปรับคะแนนและเกณฑ์ผ่าน จัดลำดับ ดูตัวอย่าง คัดลอก ดูผล และส่งออก CSV; ล็อกคำถามเมื่อมีผู้สอบเพื่อรักษาประวัติ
- ผู้ช่วย AI: เลือก Llama/Gemini บันทึกประวัติแยกผู้ใช้ ส่งคำตอบแบบสตรีม หยุดคำตอบ จำกัดคำขอ และเลือกแนบบทเรียนโดยสมัครใจ คีย์อยู่ฝั่งเซิร์ฟเวอร์
- ธีมหลักฟ้า–ขาวและตัวเลือกภาษาไทย/อังกฤษ

## ผลทดสอบ
- Production build, TypeScript ผ่าน; lint ไม่มี error มี warning เดิมใน seed
- Integration ผ่าน: สิทธิ์บัญชีและแอดมินคนสุดท้าย การระงับบัญชี กล่องร้องเรียน การแยกข้อมูล แบบทดสอบและคะแนน ความคืบหน้า เกียรติบัตรและการเพิกถอน
- ทดสอบแก้คอร์สและสร้างคอร์สด้วยตนเองผ่าน
- Llama 3.2 3B และ Qwen3 8B ตอบภาษาไทยผ่าน API ของเว็บจริง พร้อมบันทึกประวัติ
- Gemini 3.1 Flash Lite: ทดสอบตอบภาษาไทยจริงและประวัติผ่านแล้ว ตัดโมเดลรุ่นอื่นที่ยังไม่ผ่านออกจากแค็ตตาล็อก เหลือ Llama, Qwen และ Gemini รุ่นนี้
- เปิด Next.js และ Ollama เบื้องหลังที่พอร์ต 3000 และ 11434; ฐานข้อมูลเดิมอยู่พอร์ต 5433

## แก้เกียรติบัตรรายวิชา
- ใช้เกณฑ์ chapter mastery ตรงกับระบบปลดล็อกเดิม พร้อมคำนวณเปอร์เซ็นต์จากจำนวนบททั้งหมดจริง
- เปิดคลังคอร์สหรือเกียรติบัตรในบัญชีนักเรียนจะตรวจและออกย้อนหลังให้วิชาที่ผ่านแล้ว ไม่ออกซ้ำและไม่คืนเกียรติบัตรที่เพิกถอน
- ทดสอบคอร์สผสม: สอบผ่านบทแรกโดยไม่กดจบเนื้อหาได้ 50% และยังไม่มีเกียรติบัตร; เรียนบทไม่มีแบบทดสอบครบได้ 100% และเกียรติบัตร
- Build และ integration ผ่าน การเข้าสู่บัญชีนักเรียนเดิมแทนผู้ใช้เพื่อออกย้อนหลังถูก automatic approval ปฏิเสธ จึงยังไม่ยืนยันการออกจริงในบัญชีนั้น ผู้ใช้เปิดหน้าเกียรติบัตรได้โดยตรง
